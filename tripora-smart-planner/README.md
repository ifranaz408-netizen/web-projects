# 🚀 Tripora | Smart Travel Planner

A modern and responsive travel planning web app that helps users create personalized trip itineraries based on destination, duration, budget, travel style, and interests.

🌐 **Live Demo:** (https://tripora-smart-planner.netlify.app/)

---

## 📌 Overview

**Tripora** is an interactive itinerary generator that lets travelers quickly build customized day-by-day plans. Users can select their destination, trip length, budget, travel style (Solo, Couple, Family, Friends), and interests. The app then generates a complete itinerary with morning, afternoon, and evening activities, along with a budget breakdown.

---

## ✨ Features

- 📱 **Fully Responsive** – Works smoothly on mobile, tablet, and desktop
- 🎯 **Custom Trip Planner** – Input destination, duration, budget, travel style, and interests
- 🗓️ **Dynamic Itinerary** – Automatically generates day-by-day activity schedules
- 💰 **Budget Breakdown** – Shows daily spending allocation + “Make It Cheaper” option
- ➕ **Interactive Actions** – Add extra activities, reduce budget, or save trips
- 🗺️ **Popular Destinations** – Quick shortcut cards for Dubai, Istanbul, and London
- 💾 **Local Storage** – Save customized trips directly in the browser
- 💬 **Toast Notifications** – Instant feedback for user actions

---

## 🛠️ Tech Stack

- **HTML5** – Semantic structure and forms
- **CSS3** – Flexbox, Grid, custom properties, glassmorphism, and responsive design
- **JavaScript (ES6+)** – DOM manipulation, form handling, itinerary logic, and `localStorage`
- **Hosting** – Netlify
