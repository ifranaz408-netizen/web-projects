# 🚀 Nexa Digital Studio

> A modern, responsive agency website built for **Nexa Digital Studio** featuring interactive UI components, scroll-reveal animations, and seamless AI voice agent integration.

🌐 **Live Website:**(https://nexa-digital-studio.netlify.app/)

---

## 📌 Project Overview

**Nexa Digital Studio** is a clean, modern landing page designed for a digital agency offering web design, web development, UI/UX, and AI digital solutions. The platform features an interactive user interface, dynamic scroll effects, and direct integration with an AI voice assistant.

---

## ✨ Features

* 📱 **Fully Responsive:** Optimized layout for mobile devices, tablets, and desktop screens.
* 🍔 **Mobile Navigation Menu:** Sliding drawer navigation that automatically closes when a link is clicked.
* 🎨 **Modern Dark UI:** Stylish glassmorphism header, smooth gradients, and custom badges.
* 🛠️ **Services Showcase:** Interactive cards highlighting agency services.
* 💼 **Featured Work Portfolio:** Live project links embedded directly into cards.
* 🤖 **AI Voice Assistant:** Integrated widget powered by **ElevenLabs Conversational AI**.
* 📩 **Interactive Form & Toast:** Client-side form handling with auto-dismissing notification toasts.
* ⚡ **Scroll Animations:** Smooth visual transitions triggered via `IntersectionObserver`.

---

## 🛠️ Tech Stack

* **HTML5:** Semantic document markup.
* **CSS3:** Custom properties (variables), Flexbox, CSS Grid, animations, and media queries.
* **JavaScript (ES6+):** DOM manipulation, event handling, dynamic updates, and scroll animations.
* **AI Integration:** ElevenLabs AI Agent Widget.
* **Hosting:** Netlify.
