# 🚀 Web Projects Portfolio

A showcase of modern, responsive, and high-performance web applications built with clean code and production-ready architecture.

## 🛠️ Featured Projects

### 1. 🖼️ [Pixelforge — Canvas Image Editor](./pixelforge-image-editor)
An in-browser image editing studio built from scratch using HTML5 Canvas 2D API. No AI models or external libraries used.

* **Live Demo:** [pixelforgeimage.netlify.app](https://pixelforgeimage.netlify.app/)
* **Key Features:** Drag-and-drop upload, aspect ratio locking, dynamic rotation/flip, custom blur filters, format conversion (PNG/JPG/WEBP), and hotkeys (`Ctrl+O`, `Ctrl+S`).
* **Tech Stack:** Vanilla JavaScript (ES6+), CSS Grid/Variables, HTML5 Canvas API.

---

### 2. 🎨 [Nexa Digital Studio](./nexa_digital_studio)
A modern, sleek, and high-converting agency landing page designed for digital studios and creative agencies.

* **Key Features:** Responsive typography, interactive hero elements, smooth scroll navigation, dark theme aesthetic, and CSS micro-interactions.
* **Tech Stack:** HTML5, CSS3, JavaScript.

---

### 3. ⚙️ [NovaAdmin — Interactive Dashboard](./admin_dashboard)
A comprehensive backend control panel UI designed to manage platform analytics, users, and data tables efficiently.

* **Key Features:** Clean data widgets, interactive tables, responsive sidebar layout, and accessible UI controls.
* **Tech Stack:** HTML5, CSS3, JavaScript.

---

## 💻 Tech Stack Overview

- **Frontend:** HTML5, CSS3 (Custom Variables, Flexbox, Grid), Modern JavaScript (ES6+)
- **APIs & Tooling:** HTML5 Canvas API, FileReader API, Git/GitHub
- **Deployment:** Netlify
